# PaperLens 제품 브리프

PaperLens는 논문을 빠르게 읽고, 원문 근거를 확인하고, 개인 연구 라이브러리에 정리해 다시 꺼내 쓰도록 돕는 오픈소스 AI 논문 워크스페이스다. 첫 공개 버전의 약속은 사용자가 논문 하나를 가져와 Reader에서 읽고, 번역을 대조하고, 논문에 근거해 질문하고, Markdown 정리본과 노트로 남기고, 나중에 Library에서 다시 찾는 처음부터 끝까지 이어지는 제품을 공개하는 것이다.

제품의 중심은 빠른 AI Reader와 축적되는 AI Library다. Reader는 논문을 여는 순간부터 읽기와 이해를 돕고, Library는 읽은 논문, 하이라이트, 노트, 정리본, 읽기 이력을 쌓아 둔다. PaperLens가 강화하려는 루프는 `read -> evidence -> organize -> revisit -> compound`다. 넓고 모호한 "올인원 리서치 코파일럿"보다 이 구체적인 사용 흐름을 제품 언어의 중심에 둔다. 이미 논문 QA, 업로드 기반 검색, 라이브러리 정리, 인용 기반 답변을 제공하는 도구는 많으므로 PaperLens는 독점적인 기술 장벽이나 완전한 정확도를 주장하지 않는다.

## 누구를 위한 제품인가

PaperLens는 논문을 자주 읽지만 읽기와 정리가 분리되어 불편한 사람을 위한 제품이다. 대학원생, 연구자, 엔지니어, 독립 학습자처럼 PDF 원문, 번역, 질문 답변, 요약 노트, 하이라이트, 읽기 이력을 여러 도구 사이에서 옮겨 다니는 사용자가 주요 대상이다.

이 사용자의 문제는 단순히 "논문을 요약해 달라"가 아니다. 논문을 열기까지 오래 걸리고, 번역과 원문 대조가 끊기고, AI 답변이 원문 어디에 기대는지 확인하기 어렵고, 읽은 뒤의 정리물이 다음 읽기와 연결되지 않는 것이 문제다. PaperLens는 이해도를 채점하지 않고, 사용자가 핵심을 빠르게 파악하고 근거를 확인하며 자신의 연구 지식으로 보존하도록 돕는다.

## 첫 공개 릴리스 범위

첫 공개 버전은 추천 시스템과 개인 지식 그래프를 제외한 핵심 기능이 실제로 작동해야 한다. 범위는 Reader와 Library가 이어지는 하나의 완료된 흐름으로 판단한다.

- 가져오기: arXiv URL, PDF URL, 로컬 PDF 파일을 지원한다. arXiv 가져오기에서는 사용자가 URL과 저장할 라이브러리 폴더를 지정하면 PaperLens가 PDF를 가져오고 읽기 준비를 시작한다.
- Reader: PDF 원문, 문장 정렬 번역, 논문 근거 기반 QA를 한 화면에서 제공한다. 원문과 번역은 문장 단위로 대조되며, 사용자가 한쪽 문장을 볼 때 대응 문장을 확인할 수 있어야 한다.
- 정리본: 논문을 Library에 추가하면 기본 또는 사용자 정의 템플릿에 따라 Markdown 브리프를 생성한다. 정리본은 논문이 다루는 문제, 기존 방법의 한계, 제안 방법, 논문이 직접 밝힌 한계, AI가 추론한 잠재 한계, 방법의 장점과 한계, 추가 탐색 가능성을 담는다.
- 근거 연결: 정리본과 QA에는 원문으로 돌아갈 수 있는 인라인 근거를 포함한다. 논문 근거 기반 QA는 차별적 과장이 아니라 신뢰 가능한 논문 도구의 기본 조건으로 다룬다.
- Library: 논문 폴더, 논문 카드, 제목과 발행연도, 마우스를 올렸을 때 보이는 한 줄 요약 또는 Abstract 일부와 주제 태그, 하이라이트, 노트, 읽기 이력을 포함한다. 논문 카드를 선택하면 Reader로 이어지고, Reader에서 만든 기록은 다시 Library에 남는다.
- AI 연결: BYOK와 Codex OAuth를 지원한다. 사용자는 자신의 키를 가져오거나 OAuth로 연결해 AI 기능을 사용할 수 있다.

이 범위 안에서 PaperLens는 빠른 진입을 중요하게 본다. 사용자가 논문을 추가한 뒤 Reader에서 원문을 보기까지 오래 기다리면 핵심 가치를 경험하기 전에 이탈할 수 있다. 따라서 가능한 결과부터 보여주고 나머지 작업의 진행 상태를 드러내는 방향을 따른다.

## 공개와 오픈소스 방향

초기 성공은 오픈소스 제품이 실제로 사용 가능한 상태에 도달하는 것이다. [가정] 공개 이후 제품 건강 신호가 필요하다면 가져오기부터 Reader 진입, 정리본 생성, 근거 확인, Library 재방문까지의 루프 완료율과 반복 사용 여부를 볼 수 있다.

PaperLens는 잠재 사용자와 오픈소스 커뮤니티를 위한 공개 소개이며, 투자자용 성장 서사가 아니다. 커뮤니티는 읽기 UX, 근거 연결, AI 연결 방식, 연구 정리 흐름을 함께 개선할 수 있다. 라이선스는 AGPL-3.0을 고려 중이지만 아직 확정된 것은 아니다.

## 이후 비전

첫 릴리스 이후에는 논문 추천과 개인 지식 그래프를 다룬다. 추천은 사용자의 Library와 읽기 기록을 바탕으로 관련 논문이나 최신 논문을 찾는 방향이고, 지식 그래프는 논문, 태그, 정리본, 연구 주제 사이의 관계를 탐색하게 만드는 장기 기능이다. 둘 다 장기 비전에는 중요하지만 첫 공개 버전의 완료 조건에는 넣지 않는다.
