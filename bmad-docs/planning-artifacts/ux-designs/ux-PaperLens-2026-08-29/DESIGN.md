## Brand & Style

PaperLens는 논문 원문을 가장 강한 객체로 남기는 차분한 macOS 연구 도구다. 새 설치의 기본 시각 스타일은 **Native Canvas**이고, **Scholarly Press**와 **Focused Instrument**는 Settings에서 선택할 수 있는 추가 테마다. 세 테마는 모두 Light/Dark 쌍을 가지며 기능·상태의 의미는 테마에 따라 바뀌지 않는다. 테마는 glossy한 장식이나 홍보성 배너가 아니라 읽기 맥락을 보존하는 표면 교체다.

- **Native Canvas**: 따뜻한 중성 matte canvas와 조용한 system chrome, 부드러운 국소 깊이, 드문 파란 action cue. 원문 종이와 번역의 equal split이 중심이다.
- **Scholarly Press**: Charter 계열 serif, mono folio/label, firm rule과 paper tone으로 critical edition 같은 질서를 만든다. 카드와 장식을 늘리지 않는다.
- **Focused Instrument**: 차가운 luminance 단계, fine border, tabular metadata와 조밀한 컨트롤로 calibrated research instrument의 인상을 만든다.

이 세 방향은 사용자가 직접 편집하거나 내려받는 theme marketplace가 아니다. HTML 시안의 `-apple-system`, `:hover`, `:focus-visible`, `:has()` 등 브라우저 표현은 참고 구현일 뿐이며, native runtime은 macOS native control과 semantic text role을 상속하고 동일한 의미를 구현해야 한다.

앞면의 모든 색은 YAML의 flat color token으로 고정했다. 아래 값은 HTML 시안의 실제 CSS에서 추출했으며, `canvas / chrome / sidebar / panel / paper / raised / ink / muted / line / line-soft / accent / accent-soft / match / match-line / success / success-soft / error / error-soft` 역할을 Light/Dark마다 쌍으로 유지한다. `artifact-*`는 시안 페이지 바깥 배경이다.

| 방향 | Light 추출값 | Dark 추출값 |
|---|---|---|
| Native Canvas | `{colors.native-canvas-canvas-light}`, `{colors.native-canvas-ink-light}`, `{colors.native-canvas-muted-light}`, `{colors.native-canvas-accent-light}` | `{colors.native-canvas-canvas-dark}`, `{colors.native-canvas-ink-dark}`, `{colors.native-canvas-muted-dark}`, `{colors.native-canvas-accent-dark}` |
| Scholarly Press | `{colors.scholarly-press-canvas-light}`, `{colors.scholarly-press-ink-light}`, `{colors.scholarly-press-muted-light}`, `{colors.scholarly-press-accent-light}` | `{colors.scholarly-press-canvas-dark}`, `{colors.scholarly-press-ink-dark}`, `{colors.scholarly-press-muted-dark}`, `{colors.scholarly-press-accent-dark}` |
| Focused Instrument | `{colors.focused-instrument-canvas-light}`, `{colors.focused-instrument-ink-light}`, `{colors.focused-instrument-muted-light}`, `{colors.focused-instrument-accent-light}` | `{colors.focused-instrument-canvas-dark}`, `{colors.focused-instrument-ink-dark}`, `{colors.focused-instrument-muted-dark}`, `{colors.focused-instrument-accent-dark}` |

`accent`는 활성 탭·현재 목차·진행률·Evidence Anchor·primary action처럼 현재 작업점을 나타낸다. `match`/`match-line`은 대응 문장과 anchor clickback 위치를 나타낸다. `success`와 `error`는 준비됨·실패를 텍스트와 함께 구분한다.

사용자 결정에 따라 목표 미달 작은 텍스트만 최소 보정했다. 각 RGB 채널에서 같은 정수를 빼는 방식으로 해당 배경에서 4.5:1을 처음 만족하는 값을 선택했고, 비교 HTML도 같은 값으로 갱신했다. Dark 팔레트와 레이아웃은 유지한다.

| Light 텍스트 / 배경 | 이전 → 보정 | 계산 대비 |
|---|---|---|
| Native muted / sidebar | `#716E67` → `#6A6760` | 4.08 → 4.527:1 |
| Native success / success-soft | `#3F7550` → `#3C724D` | 4.37 → 4.562:1 |
| Scholarly muted / sidebar | `#69675F` → `#64625A` | 4.19 → 4.523:1 |
| Focused muted / sidebar | `#66717D` → `#616C78` | 4.22 → 4.539:1 |

이 결과는 sRGB 색상 쌍 계산이며 전체 렌더링 또는 native 접근성 감사가 아니다. 구현 acceptance target은 일반 텍스트 4.5:1 이상, 큰 텍스트·의미 있는 비텍스트·focus indicator 3:1 이상이다. 실제 적용 배경이 다르면 다시 검증하며, 여섯 테마/명암 조합 전체가 통과했다고 해석하지 않는다.

## Typography

HTML 시안에서 공통으로 추출한 UI ramp는 `11px / 12px / 13px / 15px`, 줄간격은 각각 `1.4 / 1.45 / 1.4 / 1.65` 부근이다. `Native Canvas`의 title은 17px, `Scholarly Press`는 18px, `Focused Instrument`는 16px이며, paper text는 각각 16px / 16px / 15px, 줄간격은 1.68이다. 앞면의 `{typography.text-xs}`, `{typography.text-sm}`, `{typography.text-ui}`, `{typography.text-body}`와 방향별 token은 그 추출값을 보존한다.

| 방향 | UI | 원문·읽기 | mono/meta |
|---|---|---|---|
| Native Canvas | `{typography.native-ui}` — `-apple-system`, `BlinkMacSystemFont`, `Helvetica Neue` | `{typography.native-reading}` — `ui-serif`, `New York`, Georgia | `{typography.native-mono}` — SFMono/Menlo 계열 |
| Scholarly Press | `{typography.scholarly-ui}` | `{typography.scholarly-reading}` — Charter, Iowan Old Style, Georgia | `{typography.scholarly-mono}` |
| Focused Instrument | `{typography.focused-ui}` | `{typography.focused-reading}` — Apple system/Apple SD Gothic Neo | `{typography.focused-mono}` |

한국어 Translation은 시안의 `line-break: strict`, `word-break: keep-all`, `overflow-wrap: break-word`를 유지하고 본문 줄간격 1.68을 기준으로 한다. `native-korean`, `scholarly-korean`, `focused-korean`은 한국어 글리프가 영어 serif에 묻히지 않도록 native runtime의 macOS Korean fallback을 명시한 토큰이다. 브라우저가 선택하는 실제 fallback과 native font rendering은 다를 수 있으므로 HTML의 literal `font-family`를 앱 구현의 강제 폰트 파일로 해석하지 않는다. HTML의 `paper` surface와 읽기 서체는 시안 속 종이 모형의 색·글꼴일 뿐이다. 실제 `Original PDF`의 문서 content와 PDF가 지정한 글꼴은 테마로 restyle하지 않으며, 테마가 적용되는 것은 PDF 주변 chrome와 Translation surface다.

Native macOS text role과 사용자 설정에 따른 text scaling은 native runtime이 소유한다. 시안의 px 값은 시각 비교를 위한 baseline이며, 확대 시 문장이 잘리거나 원문·Translation·상태 의미가 사라지지 않아야 한다. 한국어 copy는 임의의 영문 대문자 label로 바꾸지 않으며, Scholarly Press에서만 mono folio/label을 제한적으로 사용한다.

## Layout & Spacing

기본 HTML frame은 `1440 × 900px`, window radius는 방향에 따라 Native 16px, Scholarly 10px, Focused 12px이다. shell은 `220px` sidebar와 Reader 영역으로 나뉘고, Reader는 `50px` titlebar 아래 `52px` toolbar, `36px` job strip, `minmax` comparison, `42px` statusbar의 수직 계약을 가진다. 시안에서 확인된 equal split은 `Translation` tab의 PDF 대조 layout이며, PDF navigation이 Translation page를 제어한다. `Paper Chat` tab의 정확한 열 비율은 이 시안에서 확정하지 않는다.

| 영역 | 추출값 |
|---|---|
| frame / shell | `{spacing.frame-width}` × `{spacing.frame-height}`, sidebar `{spacing.sidebar-width}` |
| titlebar / toolbar / jobs / status | `{spacing.titlebar-height}` / `{spacing.toolbar-height}` / `{spacing.jobs-height}` / `{spacing.statusbar-height}` |
| panel | panel heading `{spacing.panel-heading-height}`, PDF scroll `{spacing.pdf-scroll-padding}`, Translation top/inline/bottom `{spacing.translation-scroll-top}` / `{spacing.translation-scroll-inline}` / `{spacing.translation-scroll-bottom}` |
| paper page | max width `{spacing.paper-page-width}`, min height `{spacing.paper-page-min-height}`, padding `{spacing.paper-page-padding-block}` × `{spacing.paper-page-padding-inline}` |
| base scale | `{spacing.1}` `{spacing.2}` `{spacing.3}` `{spacing.4}` `{spacing.5}` `{spacing.6}` `{spacing.8}` |

시안의 compact media rule은 `max-width: 1240px`이다. 이때 frame height는 `{spacing.frame-height-compact}`, sidebar는 `{spacing.sidebar-width-compact}`, 공통 inline padding은 12px, toolbar gap은 8px, PDF scroll은 `{spacing.pdf-scroll-padding-compact}`가 된다. Native Canvas와 Scholarly Press의 Translation scroll은 `20px 24px 32px`, Focused Instrument는 `20px 16px 32px` (`{spacing.translation-scroll-top-compact}`, `{spacing.translation-scroll-inline-compact}` 또는 `{spacing.translation-scroll-inline-compact-focused}`, `{spacing.translation-scroll-bottom-compact}`)이며, paper padding은 Native 32px, Scholarly/Focused 24px다. Focused Instrument compact PDF 문단은 시안에서 line-height `1.56`으로 줄어든다.

이 값은 macOS 창을 좁혔을 때의 정보 우선순위를 보여주는 **추출 기준**이다. native runtime이 동일한 1240px breakpoint, 동일한 browser `overflow:auto`, 또는 동일한 frame height를 써야 한다고 결정하지 않는다. 창 크기 변화에서 PDF 원문 접근, 현재 page, Translation 상태, action focus를 보존하는 native adaptive rule은 `[열린 결정]`이다.

## Elevation & Depth

Native Canvas 시안은 frame에 `0 24px 72px #2E2A241F, 0 0 0 1px #5C574D33`, local chrome에 `inset 0 1px 0 #FFFFFF4D, 0 1px 2px #25221D12`, light paper에 `0 12px 28px #403B321A, 0 0 0 1px #817B6F24`를 사용한다. Dark paper는 `0 14px 32px #00000033, 0 0 0 1px #7E756829`다.

Scholarly Press는 frame `0 20px 58px #2A261E24, 0 0 0 1px #312E2833`, light paper `inset 0 0 0 1px #FFFFFF80, 0 10px 24px #3A34291C`, dark paper `inset 0 0 0 1px #817B6926, 0 12px 28px #0000003D`를 쓴다. Focused Instrument는 frame `0 22px 64px #17202A2B, 0 0 0 1px #46546133`, local chrome `inset 0 1px 0 #FFFFFF47, 0 1px 2px #15202A12`, light paper `inset 0 0 0 1px #FFFFFFB3, 0 8px 22px #2131401A`, dark paper `inset 0 0 0 1px #70869A24, 0 10px 26px #00000042`다.

그림자는 hierarchy를 대신하지 않는다. panel은 `panel`/`canvas`/`paper`의 tonal layering과 line으로 구분하고, hover lift나 glossy gradient를 추가하지 않는다. 위 shadow 값은 비교 HTML의 rendering 값이며, native system elevation API를 강제하는 토큰이 아니다.

## Shapes

Native Canvas는 `5px / 8px / 12px / 16px`(small, medium, large, window)의 부드러운 사각형을 쓴다. Scholarly Press는 `0px / 2px / 10px`로 firm rule과 publication page를 강조한다. Focused Instrument는 `3px / 5px / 12px`로 calibrated control을 만든다. `rounded/full`은 9999px 값이지만 논문 surface나 상태 의미를 pill로 만들지 않는다. Native component가 제공하는 macOS alert·drawer·window corner는 OS convention을 우선하고, HTML radius를 그대로 복제하지 않는다.

## Do's and Don'ts

| Do | Don't |
|---|---|
| Native Canvas를 새 설치의 기본 theme으로 두고 Settings에서 세 theme을 같은 의미로 전환한다. | 테마를 기능 mode, 사용자 편집기, marketplace, 홍보 배너로 확장하지 않는다. |
| Light/Dark 각각의 실제 role token을 유지하고 `accent`, `match`, `success`, `error`를 text/state와 함께 쓴다. | 색 대비를 측정 완료했다고 주장하거나 색만으로 오류·선택을 구분한다. |
| PDF와 Translation을 equal split으로 배치하고 paper가 가장 강한 읽기 객체가 되게 한다. | HTML 비교 frame을 최종 mock 또는 앱 구현으로 인용하거나, 불필요한 card/gradient/gloss를 추가한다. |
| Korean paragraph flow, keep-all, strict line-break와 native text scaling을 보존한다. | 한국어 문장을 임의 truncation하거나 English-only typography를 강요한다. |
| Scholarly Press의 rule/mono와 Focused Instrument의 compact metadata를 각 theme의 역할로 제한한다. | 세 theme의 색·radius·서체를 섞어 새로운 네 번째 direction을 만든다. |
| `ReaderShell` 안에서 `PdfPanel`, `TranslationPanel`, `PaperChatPanel`, `BriefTrigger`를 같은 Paper context로 유지한다. | current page/selection을 Paper Chat에 자동 주입하거나 Translation alignment를 정확도 보장처럼 장식한다. |
| 내부 security accepted limit을 user-facing 문구에 노출하지 않으면서, local-only/privacy/forensic deletion 같은 거짓 claim도 하지 않는다. | 외부 Provider, 삭제 범위, 보안 상태에 대해 근거 없는 안심·홍보 문구를 만든다. |
| 충돌 시 이 spine와 EXPERIENCE.md를 HTML보다 우선한다. | `[열린 결정]`을 조용히 기본값으로 채우거나 FR-037..039/SM-007을 승인된 제품 범위로 표기한다. |
