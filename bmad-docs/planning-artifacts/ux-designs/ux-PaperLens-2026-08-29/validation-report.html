bmad-docs/planning-artifacts/ux-designs/ux-PaperLens-2026-08-29/review-rubric.md · 선택된 completeness rubric

최종 초안은 이전 문서 완전성 검토의 여덟 지적을 모두 닫았다. 네 사용자 여정에 Settings, Library, 네 가지 Import branch, Brief 필수 내용, Chat Session relaunch 동작이 들어갔고, 추가 컴포넌트와 상태 행이 두 spine에서 짝을 이루며, 보정된 Light token과 pending_sources 기반 thematic amendment 격리가 기록됐다. 선택된 completeness rubric 기준의 현재 미해결 finding은 없다.

이 보고서는 rubric walker만 통합한다. 새 HTML 생성과 mockups/ 승격은 보고 시점에 진행 중이므로 파일 존재·렌더링·승격은 부모의 통합 확인 범위이며 결함으로 세지 않았다. 정적 mock은 구현·동작·접근성·대비 QA 증거가 아니다. thematic amendment의 PRODUCT 재승인은 여전히 필요하고, 이 보고서나 문서의 명시적 결정으로 승인·구현 권한을 추론하지 않는다.

  • High — Light 작은 텍스트 대비: Native muted/success, Scholarly muted, Focused muted의 보정값과 계산 결과가 DESIGN.md:452-461에 기록됐다.
  • High — Provider/language flow: ProviderSettings, TranslationLanguageControl과 UJ-1 Settings 하위 흐름이 last-good 연결, 재테스트 실패, 새/재생성 Job 적용을 명시한다 (EXPERIENCE.md:69-74, :208-216).
  • High — Library organization/detail: UJ-3과 두 Library control이 Folder·tag·Reading Status·Favorite, abstract/topic detail, empty/no-match 및 재진입 보존을 명시한다 (EXPERIENCE.md:77-80, :240-250).
  • High — FR-021 Brief: BriefView, Brief state row, UJ-1이 일곱 required section과 missing-content를 명시한다 (EXPERIENCE.md:89-90, :115, :202-204).
  • High — component pair: Settings/Library/Brief control rows가 두 spine에 대응하고 inherited-control behavioral delta를 명시한다 (EXPERIENCE.md:65-99, DESIGN.md:505-542).
  • High — Settings state: Provider status/retest, language, Template return, appearance/relaunch를 포함한 Settings row가 추가됐다 (EXPERIENCE.md:108).

  • Medium — 네 Import branch: arXiv abstract/PDF, 일반 PDF, local PDF가 IA·state·interaction·UJ-1에 명시된다 (EXPERIENCE.md:45, :110, :132, :194-198).
  • Medium — Chat relaunch: autosave와 relaunch-restored state, UJ-4의 앱 종료·재실행 복원이 추가됐다 (EXPERIENCE.md:118, :260-266).
  • Medium — appearance policy: System 기본 및 Settings System/Light/Dark 결정이 pending amendment 표식 아래 격리됐다 (EXPERIENCE.md:273-280, :132).
  • Medium — mock 범위: 여덟 key-screen 그룹이 정적 참조로 선언됐다 (EXPERIENCE.md:169-184, DESIGN.md:509-516). 파일 존재·승격은 부모가 확인한다.

1. Flow coverage

strong

네 UJ는 named protagonist, numbered steps, climax, failure path를 유지한다. UJ-1에는 네 Import branch, Settings 재확인, 일곱 Brief section이 있고, UJ-3에는 Library organization, UJ-4에는 자동 저장과 relaunch 복원이 있다 (EXPERIENCE.md:186-272).

현재 finding: 없음.

이전 지적 종료: Provider/language controls, Library organization/detail, FR-021 Brief content, 네 Import inputs, Chat relaunch가 각각 Settings 하위 흐름·추가 component/state 계약·UJ 확장으로 닫혔다 (EXPERIENCE.md:45, :69-80, :89-90, :110, :118, :132, :194-216, :240-271).

2. Token completeness

strong

YAML의 Light/Dark role pair, typography, rounded, spacing, component reference가 유지되며, 승인된 작은 텍스트 보정값과 계산 결과가 기록됐다 (DESIGN.md:1-23, :440-462). 전체 native 접근성 감사나 여섯 조합 전체 QA를 주장하지 않는다.

현재 finding: 없음.

이전 지적 종료: Native muted #6A6760, Native success #3C724D, Scholarly muted #64625A, Focused muted #616C78와 계산 결과가 기록되어 이전 Light 작은 텍스트 대비 finding을 닫았다 (DESIGN.md:452-461).

3. Component coverage

strong

기존 컴포넌트와 ProviderSettings, TranslationLanguageControl, LibraryOrganizationControls, LibrarySearchFilters, BriefView, AppearancePicker가 DESIGN/EXPERIENCE 양쪽에 대응한다 (EXPERIENCE.md:65-99, DESIGN.md:505-542). macOS inherited control의 behavioral delta도 명시된다.

현재 finding: 없음.

이전 지적 종료: Settings, Library, 독립 Brief의 unnamed control 문제를 six paired rows와 inherited-control 선언이 닫았다.

4. State coverage

strong

Settings, Library organization, 네 Import branch, Brief missing-content, Chat autosave/relaunch와 기존 Reader/Job/deletion/Template/evidence 상태가 matrix에 있다 (EXPERIENCE.md:101-119). appearance 행은 pending amendment로 분명히 격리되어 있다.

현재 finding: 없음.

이전 지적 종료: Settings row가 Provider status/retest, language, Template return, appearance/relaunch를 다루고, 사용자의 System 기본 및 Settings System/Light/Dark 결정이 기록됐다 (EXPERIENCE.md:108, :119, :273-280).

5. Visual reference coverage

adequate

Reader 비교와 여덟 key-screen 그룹의 범위·illustration·한계가 선언되어 있다 (EXPERIENCE.md:169-184, DESIGN.md:509-516). 새 HTML 생성과 mockups/ promotion의 파일 존재·렌더링·승격은 부모가 확인할 실제 통합 작업이다.

현재 finding: 없음.

이전 지적 종료: Onboarding, Import, Library, Settings, Paper Chat, Brief, Notes, Template의 여덟 key-screen 그룹을 정적 참조로 선언했다. 생성·승격 진행 중인 파일의 존재를 이 보고서가 검증했다고 주장하지 않는다.

6. Bloat & overspecification

strong

추가된 rows와 mock 선언은 기존 누락된 load-bearing requirement를 닫기 위한 것이며, DESIGN은 시각 계약, EXPERIENCE는 행동·상태·flow·source classification을 소유한다 (DESIGN.md:440-462, :505-542; EXPERIENCE.md:65-119, :169-184).

현재 finding: 없음.

7. Inheritance discipline

strong

승인된 Product/Architecture commit pin은 유지되고, thematic working-tree 자료는 pending_sources와 명시적 non-authority label로 분리된다. token path와 component names도 두 spine에서 대응한다 (DESIGN.md:1-23, :425-438; EXPERIENCE.md:1-24, :39-49).

현재 finding: 없음.

이전 지적 종료: `pending_sources`와 [PENDING PRODUCT AMENDMENT — NOT IMPLEMENTATION AUTHORITY] 표식이 thematic amendment를 격리한다. PRODUCT 재승인은 별도 governance 단계다.

8. Shape fit

strong

DESIGN canonical section order와 EXPERIENCE required sections, triggered Responsive & Platform / Inspiration & Anti-patterns가 유지된다 (DESIGN.md:425-563; EXPERIENCE.md:26-169).

현재 finding: 없음.

compact breakpoint, pointer target, Reduce Motion, global shortcut, modal stacking, Template validation은 implementation/Build Spec detail로 명시되어 있으며 completeness finding으로 만들지 않았다.

Precise limitations and scope boundaries

  • 별도 editorial structure/prose reviewer는 선택된 extra reviewer가 아니며, 추가 결과는 생성하지 않았다.
  • 새 HTML의 실제 존재·렌더링·mockups/ 승격은 보고 시점에 진행 중인 부모 통합 확인 범위다. 정적 mock은 native behavior, browser/static QA, screen-reader QA, contrast audit, restart recovery, deletion saga proof가 아니다.
  • FR-037..FR-039/SM-007 thematic amendment는 격리됐지만 PRODUCT 재승인을 받지 않았다. 이 보고서는 schema, source approval, implementation approval을 만들지 않는다.
  • Native compact breakpoint, pointer target, Reduce Motion, global shortcut, modal stacking, Template validation은 implementation/Build Spec detail이며 completeness finding으로 분류하지 않았다.
