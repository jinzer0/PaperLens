PaperLens · key screen 04

TemplateEditor · Settings

Brief의 `Template 관리`에서 진입하는 dedicated Settings editor를 정적 Native Canvas 시안으로 표현했다. Markdown section과 prompt를 저장한 뒤 originating Brief로 돌아가지만, 선택 상태만 갱신되고 자동 Brief regeneration은 시작되지 않는다.

Caption
Dedicated Settings template editor with Markdown sections/prompts; save returns to the originating Brief without autoregen.
Source mapping
UJ-4 steps 1–4; TemplateSelector, TemplateEditor, Settings IA, and Template state patterns.
Artifact status
Native Canvas Light/Dark reference only · static labels, no JavaScript, no network.

TemplateEditor

Paper Brief의 Markdown sections와 prompts를 편집합니다.

Template 이름
세미나 준비
Markdown sections / prompts
Markdown재사용 가능한 user Template

## 핵심 주장

논문의 핵심 주장을 원문 근거와 함께 요약한다.

Prompt · 주장마다 source page와 sentence를 확인한다.

## 방법

입력, 계산 과정, 모델의 주요 단계를 짧게 정리한다.

Prompt · 수식과 query/key/value 관계를 보존한다.

## 확인할 점

논문이 직접 말하지 않는 결론은 별도로 표시한다.

Prompt · 근거가 부족한 항목을 anchored success로 바꾸지 않는다.

## 세미나 질문

후속 토론에서 확인할 질문을 한 줄씩 남긴다.

Prompt · Scaled Dot-Product Attention의 √dk 스케일링을 질문으로 연결한다.

Template content는 Paper와 독립적으로 남는다. 저장 후 originating Brief context로 돌아간다.

Reusable user Template

세미나 준비

Paper-independent template · 현재 Paper Brief에서 선택 중

Reference Paper
Attention Is All You Need
Vaswani et al. · 2017

저장 후 흐름

저장하면 originating Brief로 돌아가고, 이 Template이 selected 상태가 된다.

자동 Brief 재생성 없음
Brief 재생성은 돌아온 뒤 사용자가 명시적으로 선택한다.
TemplateEditor · Settings dedicated surfaceSave → originating Brief · selected template 유지
Saved · return state

Brief로 돌아옴 · 세미나 준비 선택됨

저장 결과가 originating Brief에 반영됐다. 기존 Brief 본문은 그대로 남고, 재생성은 아직 시작되지 않았다.

저장됨 · 자동 재생성 안 함

Brief · Attention Is All You Need

selected: 세미나 준비

Scaled Dot-Product Attention은 내적을 √dk로 나누어 softmax의 작은 gradient 문제를 완화한다. 이 prior Brief는 사용 가능 상태로 보존된다.

Mapping: UJ-4 최준호 steps 1–4 · `TemplateSelector` → `TemplateEditor` → originating `Brief` · `Template` state.
