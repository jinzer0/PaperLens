3.2.1 Scaled Dot-Product Attention

We call our particular attention “Scaled Dot-Product Attention.” The input consists of queries and keys of dimension dk, and values of dimension dv.

We compute the dot products of the query with all keys, divide each by √dk, and apply a softmax function to obtain the weights on the values.

Attention(Q, K, V) = softmax(QKᵀ / √dk)V

We suspect that for large values of dk, the dot products grow large in magnitude, pushing the softmax function into regions where it has extremely small gradients. To counteract this effect, we scale the dot products by 1 / √dk.

In practice, we compute the attention function on a set of queries simultaneously, packed together into a matrix Q.
