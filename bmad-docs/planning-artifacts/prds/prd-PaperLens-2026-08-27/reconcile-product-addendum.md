## 판정 요약

제품 브리프 부록의 주요 확정 방향은 PRD 본문과 PRD 부록에 대부분 반영되어 있다. v1 범위, Reader의 원문과 번역과 Paper Chat 결합, 문장 단위 1대1 대조, 근거 기반 정리본, Library 재방문 루프, EasyPaper 라이선스 제약, AGPL-3.0 미확정 상태, 추천과 개인 지식 그래프 제외는 명확하게 보존됐다.

다만 일부 후보와 화면 우선순위 항목은 PRD에 요구사항으로 옮겨지지 않았고, 명시적으로 주차되거나 제외됐다는 표시도 없다. 특히 Library 첫 화면의 최근 읽은 논문, 논문 목록의 한 줄 요약 노출 방식, 일부 후속 비전 아이디어가 누락되어 있다. 최신 PRD 결정이 브리프 표현을 정당하게 대체한 항목도 있으며, Codex OAuth, 로컬 모델, Paper Chat 모드 분리, PDF 파싱 기술 선택이 여기에 해당한다.

## 핵심 갭

### GAP-001: Library 첫 화면의 최근 읽은 논문 후보가 반영 또는 주차되지 않음

상태: 갭

출처: 제품 브리프 부록 `Library`, `[후보] 라이브러리 첫 화면에는 최근 읽은 논문을 보여준다.`

대상 확인:

1. PRD `6. 정보 구조`는 Library를 폴더, 논문 목록과 카드, 태그, 검색과 필터, 읽기 상태, 하이라이트, 노트, 읽기 이력, 삭제로 정의한다.
2. PRD `FG8. Library와 개인 연구 기록`의 FR-075부터 FR-088은 Library 통합 관리, 폴더, 이동, 카드 표시, 태그, 검색과 필터, 읽기 상태, 하이라이트, 노트, 읽기 이력, 카드 클릭, 삭제를 다룬다.
3. PRD `5. 사용자 여정`은 나중에 Library에서 검색과 필터로 다시 찾고 논문 카드를 열어 Reader로 돌아가는 흐름을 설명한다.

판정: 최근 읽은 논문을 Library 첫 화면에 우선 노출한다는 후보는 PRD 본문 요구사항에도, PRD 부록의 후속 검토 항목에도 없다. 읽기 이력 자체는 FR-075, FR-085, FR-088 및 `6. 정보 구조`에 반영되어 있지만, Library 홈 또는 첫 화면의 기본 구성 결정은 빠져 있다.

영향: Reader에서 읽은 논문을 다시 찾는 `revisit` 경험의 첫 진입점이 검색과 필터 중심으로만 정의된다. 사용자가 방금 읽던 논문으로 돌아가는 Library UX가 제품 브리프 후보보다 약해질 수 있다.

권장 처리: UX 단계에서 검토할 후보로 PRD 부록에 주차하거나, PRD `FG8`에 Library 기본 화면 또는 최근 읽은 논문 섹션 요구사항을 추가하는 것이 적절하다.

### GAP-002: 논문 목록의 한 줄 요약 상시 노출 후보가 hover 노출로만 흡수됨

상태: 부분 갭

출처: 제품 브리프 부록 `Library`, `[후보] 논문 목록에 한 줄 요약을 표시해 사용자가 논문 내용을 빠르게 회상하게 한다.`

대상 확인:

1. PRD `FG8. Library와 개인 연구 기록`의 FR-078은 논문 카드에 제목과 발행연도를 항상 표시해야 한다고 정의한다.
2. FR-079는 한 줄 요약, Abstract 일부, 주제 태그를 논문 카드 hover 시 표시해야 한다고 정의한다.
3. PRD `4.1 v1 포함 범위`에는 논문 카드가 포함되지만 목록 밀도나 요약의 상시 노출은 별도 요구사항으로 없다.

판정: 한 줄 요약이라는 콘텐츠 자체는 FR-079에 반영됐다. 그러나 출처 후보의 의도는 논문 목록에서 빠르게 회상하도록 한 줄 요약을 표시하는 것이며, PRD는 이를 hover 전용 보조 정보로 제한했다. 최신 결정으로 supersede됐다는 설명은 없다.

영향: Library 재방문 사용자가 여러 논문을 훑으며 내용을 빠르게 떠올리는 경험이 약해질 수 있다. hover 기반 노출은 데스크톱 카드 UX에는 맞지만, 목록 스캔 효율을 목표로 한 후보와는 다르다.

권장 처리: FR-079를 최신 결정으로 볼지 확인해야 한다. hover 전용이 의도된 축소라면 PRD 부록이나 열린 질문에 명시적으로 남기는 편이 안전하다.

### GAP-003: 후속 비전의 일반 목적 독립 AI 채팅 병행 아이디어가 명시적 제외로만 남고 이후 후보로는 주차되지 않음

상태: 의도적 supersede 가능성이 큰 갭

출처: 제품 브리프 부록 `후속 비전`, `[후보] 일반 목적 독립 AI 채팅과 논문 근거 기반 질문 답변 병행`

대상 확인:

1. PRD `4.2 v1 비목표`는 Paper Chat의 일반 채팅 모드와 논문 QA 모드 분리를 제외한다.
2. PRD `FG5. Paper Chat`의 FR-038부터 FR-040은 Paper QA와 일반 AI Chat을 분리하지 않고, 하나의 Paper Chat이 항상 논문 근거 QA 상태이며, 근거 기반 모드를 켜고 끄는 UI를 제공하지 않는다고 정의한다.
3. PRD 부록 `1. 권위와 충돌 처리`는 Paper Chat이 두 모드가 아니라 항상 논문 근거 QA가 활성화된 하나의 Chat이라고 밝힌다.
4. PRD `14. 이후 비전`에는 일반 목적 독립 AI 채팅 병행이 포함되어 있지 않다.

판정: v1에 대해서는 최신 PRD 결정이 출처 후보를 명확히 대체한다. 그러나 출처는 `후속 비전` 항목으로도 병행 아이디어를 보존하고 있었고, PRD의 이후 비전에는 이 항목이 없다. 의도적으로 폐기된 결정일 수 있지만, 폐기 또는 주차 여부가 명시돼 있지는 않다.

영향: 장기 로드맵에서 PaperLens가 논문 근거 QA만 유지할지, 나중에 일반 목적 연구 채팅을 다시 검토할지가 불명확하다.

권장 처리: 최신 결정이 장기 방향까지 폐기한 것인지 확인해야 한다. 장기 후보로도 제외한다면 PRD 부록의 권위와 충돌 처리에 명시적 폐기 사유를 남기는 것이 좋다.

### GAP-004: 읽기 전 브리핑의 `질문 거리 제공`과 `연구 계보`는 보존됐지만 브리핑 경험의 범위는 흐릿함

상태: 경미한 부분 갭

출처: 제품 브리프 부록 `후속 비전`, `[후보] 읽기 전 브리핑에 핵심 개요와 연구 계보, 파인만식 설명, 용어집, 질문 거리 제공`

대상 확인:

1. PRD `14. 이후 비전`은 읽기 전 브리핑, 파인만식 설명, 용어집, 질문 거리 제공을 포함한다.
2. PRD 부록 `8. 후속 범위 후보`는 읽기 전 브리핑의 핵심 개요와 연구 계보, 파인만식 설명, 용어집, 질문 거리 제공을 더 구체적으로 보존한다.

판정: 항목 자체는 보존됐다. 다만 PRD 본문 `14. 이후 비전`에서는 브리핑의 핵심 개요와 연구 계보가 축약되어, 본문만 읽는 리뷰어는 읽기 전 브리핑이 어떤 성격의 후보인지 덜 알 수 있다. PRD 부록에는 충분히 남아 있으므로 요구사항 갭은 아니다.

영향: 낮음. 후속 UX나 Architecture가 PRD 부록까지 참조한다면 손실은 없다.

권장 처리: 본문 유지가 짧은 이후 비전 요약이라는 목적이라면 현 상태도 허용된다. 후속 로드맵 가시성이 중요하면 PRD `14. 이후 비전`에 `핵심 개요와 연구 계보` 정도를 같이 적는 편이 낫다.

## 반영 완료 항목

### v1 범위와 범위 제외

출처 항목: 첫 공개 버전은 추천과 개인 지식 그래프를 제외하고, 가져오기부터 읽기, 번역, 근거 확인, 질문 답변, 정리, 재방문까지 이어지는 흐름을 실제로 작동시킨다.

대상 반영:

1. PRD `1. 제품 개요`는 v1 약속을 논문 가져오기, Reader 읽기, 문장 정렬 번역, 근거 기반 질문, Markdown 정리본과 노트, Library 재방문 흐름으로 정의한다.
2. PRD `4.1 v1 포함 범위`는 arXiv abstract URL, arXiv PDF URL, 일반 PDF URL, 로컬 PDF, PDF Reader, 문장 정렬 번역, 근거 기반 Paper Chat, Markdown 정리본, 사용자 정의 템플릿, 인라인 근거, Library, 하이라이트, 노트, 오류와 복구를 포함한다.
3. PRD `4.2 v1 비목표`는 추천 시스템과 개인 지식 그래프를 제외한다.
4. PRD `FG2`부터 `FG9`까지가 해당 사용자 흐름을 FR-010부터 FR-095로 쪼개 반영한다.

판정: 반영 완료.

### Reader 핵심 경험

출처 항목: Reader는 PDF 원문, 번역, AI 채팅이 함께 있는 화면이고, 번역과 질문을 즉시 사용할 수 있어야 하며, 번역 패널과 AI 채팅은 자동으로 읽기 맥락을 공유하지 않는다. 원문과 번역은 문장 단위 1대1 대조이며 양방향 hover 강조를 제공한다.

대상 반영:

1. PRD `6. 정보 구조`는 Reader를 PDF 원문, 번역 패널, Paper Chat, 정리본 Drawer, 하이라이트와 노트, PDF 탐색 도구로 정의한다.
2. FR-018은 PDF 원문, 번역, Paper Chat을 함께 제공하는 화면을 요구한다.
3. FR-028부터 FR-031은 문장 단위 1대1 대조, 원문 hover 시 번역 강조, 번역 hover 시 원문 강조, 회색 배경 등 명확한 시각 상태를 요구한다.
4. FR-051과 FR-052는 번역 패널과 Paper Chat의 자동 맥락 공유 금지와 별도 상호작용 설계 필요를 반영한다.

판정: 반영 완료.

### Reader 성능과 준비 상태

출처 항목: arXiv URL 제출 후 30초 내 PDF 원문 노출 목표, 30초 안에 준비되지 않는 AI 작업별 진행률, 번역 우선 노출, 느린 Reader 준비가 핵심 실패 요인이라는 제약.

대상 반영:

1. PRD `9.1 성능과 준비 상태`의 NFR-001은 arXiv URL 제출 후 PDF 원문을 볼 수 있을 때까지 최대 30초를 목표로 둔다.
2. NFR-003은 30초 안에 완료되지 않은 AI 작업이 Reader 진입을 막지 않고 작업별 진행 상태로 분리되어야 한다고 한다.
3. NFR-004는 PDF 원문 접근을 AI 작업 완료보다 우선한다고 한다.
4. FR-090부터 FR-095는 비동기 작업 상태, 30초 이후 진행률, 번역 결과 우선 노출, 재시도, 사용 가능한 결과 유지, 재실행 후 상태 이해를 요구한다.
5. PRD 부록 `3. Reader와 번역 구현 메모`는 페이지 단위 번역, 완료 페이지 우선 노출, 원문 즉시 표시, 번역 패널 로딩 상태를 보존한다.

판정: 반영 완료. 구현 방식은 PRD 본문이 아니라 PRD 부록에 있는 것이 적절하다.

### 정리본, 근거, 화면 이동

출처 항목: Library 추가 시 구조화된 Markdown 정리본 생성, 기본 정리본 구성, 사용자 정의 템플릿, 논문이 밝힌 한계와 AI가 분석한 가능성 있는 한계 분리, 인라인 근거, hover 미리보기, 클릭 시 PDF 문장 위치 이동, 독립 정리본 화면, Reader Drawer.

대상 반영:

1. PRD `FG6. Markdown 정리본과 템플릿`의 FR-053부터 FR-069가 정리본 생성, 기본 항목, 한계 분리, 기본과 사용자 정의 템플릿, 템플릿 편집, 재생성, 독립 화면, Drawer, 실패 상태를 반영한다.
2. PRD `FG7. 근거 연결`의 FR-070부터 FR-074가 정리본과 Paper Chat의 인라인 근거, hover 원문 미리보기, PDF 문장 위치 이동, Reader 문맥 보존을 반영한다.
3. PRD `5. 사용자 여정`은 정리본 탭과 Reader Drawer를 모두 설명한다.

판정: 반영 완료.

### Library 기본 기록 기능

출처 항목: Library는 논문 정리와 읽기 히스토리를 통합 관리하고, 카드에는 제목과 발행연도를 항상 표시하며, 한 줄 요약, Abstract 일부, 주제 태그는 hover 시 표시하고, 카드 클릭 시 PDF Reader로 이동한다.

대상 반영:

1. FR-075는 Library가 논문 정리와 읽기 히스토리를 통합 관리해야 한다고 한다.
2. FR-078은 제목과 발행연도 상시 표시를 반영한다.
3. FR-079는 한 줄 요약, Abstract 일부, 주제 태그의 hover 표시를 반영한다.
4. FR-086은 Library 카드 클릭 시 PDF Reader 이동을 반영한다.
5. FR-083부터 FR-085는 하이라이트, 노트, 정리본, 읽기 이력 보존을 반영한다.

판정: 대부분 반영 완료. 다만 GAP-001과 GAP-002의 첫 화면과 목록 요약 노출 방식은 별도 확인이 필요하다.

### EasyPaper 참조와 라이선스 제약

출처 항목: EasyPaper는 Reader UX 레퍼런스 후보이며, 문장 태그, 페이지별 스트리밍 번역, 양방향 hover 강조, 페이지 높이 동기화, 연속 스크롤, lazy rendering 등을 참고할 수 있다. LICENSE 파일이 없으므로 코드 재사용 권한을 전제로 삼지 않고 UX 영감으로만 사용해야 한다.

대상 반영:

1. PRD `10. 제약과 가드레일`은 EasyPaper 등 외부 제품은 UX 영감으로만 참고하고 코드를 재사용하지 않는다고 한다.

4. FR-037과 NFR-008은 정렬이 흔들릴 수 있는 경우와 fallback이나 보정에 대해 정확도 보장을 주장하지 않는다고 한다.

## 최신 PRD 결정으로 명시 대체된 항목
